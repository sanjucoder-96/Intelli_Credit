# data/real — real public training datasets

This tree holds **real public datasets only**. Everything a model trains on
lives here; nothing generated by this project may ever be placed here. The
separation from `data/synthetic/` is structural, not disciplinary
(ADR-0010, `docs/adr/ADR-0010-ml-datasets-and-synthetic-separation.md`):

- Every dataset row and entity carries `data_origin = REAL` (the `DataOrigin`
  enum in `backend/app/domain/enums.py`; ADR-0010 calls this `REAL_PUBLIC`).
- Training manifests may reference **only** paths under `data/real/`.
- Training-set lineage hashes are recorded in the `ml_models` registry table.
- **CI guard rule: the build fails if any training manifest references
  `SYNTHETIC_DEMO` data.** The guard ships together with the first trained
  model in Phase 6 — it must exist before the first champion is promoted.

Download instructions, licensing notes, and `pandera` validation schemas are
checked in alongside the Phase-6 training pipeline (`ml/` package).

## Rules

- Dataset files are **never committed** (see `.gitignore` — only this README
  and `.gitkeep` are tracked). They are downloaded locally per the Phase-6
  instructions.
- Never copy, symlink, or generate anything from `data/synthetic/` into this
  tree.
